# Data model

PostgreSQL is the source of truth. Use UUIDv7 identifiers generated by the application, UTC timestamps, explicit constraints/foreign keys and integer minor units for money (`AZN` qÉ™pik). Lifecycle states are explicit; important records are archived/soft-deleted rather than silently destroyed.

## Core aggregates

- identity: `users`, `accounts`, `sessions`, `verifications`, `user_roles`, `role_capabilities`;
- geography: `locations`, `location_translations`, `location_aliases`;
- catalog: `categories`, `category_translations`, `attribute_definitions`, `attribute_options`, translation tables and category assignments;
- listings: `listing_drafts`, `listings`, `listing_attribute_values`, `listing_media`, `listing_status_history`;
- commerce/trust: `shops`, `shop_members`, `favorites`, `saved_searches`, `conversations`, `messages`, `ratings`, `reports`, `moderation_cases`, `risk_signals`, `audit_events`;
- operations: `outbox_jobs`, `idempotency_keys`, `notifications`, `promotion_orders`, `payment_attempts`.
