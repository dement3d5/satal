# Data model

PostgreSQL is the source of truth. Use UUIDv7 identifiers generated by the application, UTC timestamps, explicit constraints/foreign keys and integer minor units for money (`AZN` qəpik). Lifecycle states are explicit; important records are archived/soft-deleted rather than silently destroyed.

## Core aggregates

- identity: `users`, `accounts`, `sessions`, `verifications`, `user_roles`, `role_capabilities`;
- geography: `locations`, `location_translations`, `location_aliases`;
- catalog: `categories`, `category_translations`, `attribute_definitions`, `attribute_options`, translation tables and category assignments;
- listings: `listing_drafts`, `listings`, `listing_attribute_values`, `listing_media`, `listing_status_history`;
- commerce/trust: `shops`, `shop_members`, `favorites`, `saved_searches`, `conversations`, `messages`, `ratings`, `reports`, `moderation_cases`, `risk_signals`, `audit_events`;
- operations: `outbox_jobs`, `idempotency_keys`, `notifications`, `promotion_orders`, `payment_attempts`.

## Categories and attributes

Categories use stable IDs/slugs independent of locale and support at most three true hierarchy levels. Brand/model and similar dimensions are attributes, not deeper categories.

Attribute definitions store type, unit, required/searchable/filterable/sortable flags, validation rules, order and localized labels. Values use a typed EAV table with mutually exclusive columns (`text`, `number`, `boolean`, `date`, `option_id`) enforced by checks. This remains queryable and constrained without a giant unvalidated JSON blob. A compact JSON read projection may be derived for rendering; Typesense receives denormalized facets.

## Listing lifecycle

`draft → pending_review|active → sold|expired|archived|rejected|removed` with controlled transitions and history. Publication and indexing are idempotent. Default expiry is 30 days and data is retained for renewal, audit and policy requirements.

## Location privacy

Store private precise coordinates only where needed. Public listing projections expose a district or deliberately perturbed point for private sellers. Businesses may explicitly publish an address. PostGIS can be enabled when distance search is introduced; it is not required for the first scaffold.

## Index strategy

Indexes follow actual access paths: active listings by category/location/freshness, ownership/status management, conversation membership, moderation queues, outbox availability and unique idempotency/provider references. Add specialized indexes with measured queries, not speculatively.
